Export to Figma

  1. Keep FlowMap running.
  2. In Figma: Plugins → Development → Import plugin from manifest…
  3. Choose the figma-plugin/manifest.json file in this project.
  4. Run FlowMap Import. It places one frame per step, with a screenshot of the screen.

Connect Google

  1. Open the Google Auth clients page. If it says the auth platform is not configured, click Get started.
  2. Enable the Google Analytics Data API and the Google Analytics Admin API.

  4. On Audience, add the Google account that can see Analytics as a test user.
